# Isla · Cartão de visita 3D

Configurador 3D do cartão de visita de Marcos Hollmann (Isla): layouts, acabamentos reais e preço estimado em São Paulo.

Site estático, sem build. Abra `index.html` ou publique a pasta em qualquer host estático.

## Deploy na Vercel
1. Crie um repositório no GitHub e envie estes arquivos.
2. Em vercel.com/new, importe o repositório.
3. Framework Preset: **Other**. Build command: vazio. Output directory: `.`
